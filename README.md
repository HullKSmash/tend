# Tend
Give back to the places you love.

Coded with Claude, Readme written by Katie (a human).  

Tend searches for volunteer opportunities for SF Bay Area trail and park users to give back to our green spaces through volunteer work.  The search looks at a number of local nonprofits and public divisions that maintain and restore our local trail systems, parks, wildlife habitats, shorelines, and other open spaces.  The opportunities are refreshed weekly by an agent.

Check it out at https://tendtoyourworld.vercel.app/
